# Maps

The maps in `maps/` (market, yard, harbour, depot) were generated with Tencent HY-World and processed with
`tools/add-map.sh`. Generated content from HY-World is subject to the Tencent HY-World license, which among other
things excludes use in the European Union, the United Kingdom and South Korea, and requires a separate commercial
license above one million monthly active users. Check the current license before using these maps; the game code
itself is under `LICENSE.md`.

`maps/standin.json` is a procedural courtyard built in code and is covered by `LICENSE.md`.
